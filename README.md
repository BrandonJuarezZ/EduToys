# EduToys

Landing page de una juguetería educativa con catálogo de productos, información institucional, políticas de seguridad y formulario de contacto.

## Estructura

- `index.html`: página completa con todas las secciones de la landing.
- `styles.css`: estilos visuales y diseño responsive.
- `app.js`: saludo dinámico, interacción del catálogo y validación visual del formulario.
- `logo.png`: identidad visual de EduToys.

El sitio funciona como una sola página. La navegación principal utiliza anclas internas (`#inicio`, `#nosotros`, `#productos`, `#seguridad` y `#contacto`).

## Uso local

Abre `index.html` en un navegador web. No requiere instalación ni servidor.
